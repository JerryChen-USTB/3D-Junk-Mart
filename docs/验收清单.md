# 验收清单

下面这份可以直接当你的 UAT/展示采集清单用。建议按 `P0 主链路 -> P1 配套能力 -> P2 质量体验` 顺序验收，并且每一项都同时记录：

- 结果：`通过 / 不通过 / 有瑕疵`
- 证据：`截图 / 录屏 / 接口返回 / 异常日志`
- 备注：`复现步骤 / 账号 / 设备 / 网络环境`

**一、前置准备**
- [ ] 后端可正常启动，Flutter 客户端可正常启动。
- [ ] 准备至少 4 个身份：`游客`、`买家`、`卖家`、`第二买家/第二卖家`。
- [ ] 准备至少 4 类商品：`3D 已就绪且可议价`、`3D 已就绪且不可议价`、`普通商品`、`卖家自己的草稿/在售商品`。
- [ ] 买家至少准备 2 个地址：`默认地址`、`非默认地址`。
- [ ] 如果要验收 3DGS 训练发布全链路，确认远端 trainer 可连通；否则只验已有 3D 商品的展示链路。
- [ ] 验收设备至少包含：`Android 真机窄屏`、`桌面模拟器/大屏`。
- [ ] 每次验收都记录版本、日期、接口地址、是否校园网/内网。

**二、通用通过标准**
- [ ] 功能可完成，不出现阻塞型空白页、无响应按钮、错误跳转。
- [ ] 页面刷新后数据状态正确，不是只在当前页面假更新。
- [ ] 角色权限正确：游客、买家、卖家不能做错角色的动作。
- [ ] 加载态、空态、错误态都能正常显示，不崩溃。
- [ ] 小屏设备无明显遮挡、溢出、底部按钮不可点、键盘顶起后输入框消失。
- [ ] 关键动作后有正确副作用：订单状态、通知、钱包流水、收藏状态、评价状态同步变化。

**三、P0 主链路验收：逛、看、问、下单**
**1. 登录、注册、游客模式**
- [ ] 注册成功后可自动进入已登录态。
- [ ] 登录成功后首页、搜索、消息、我的都可访问。
- [ ] 游客可浏览首页、搜索、商品详情、3D 预览。
- [ ] 游客点击下单、聊天、发布、交易类入口时会被正确拦截。
- [ ] 退出登录后回到游客/未登录态。
- 素材：录一段 `游客浏览 -> 触发登录拦截 -> 登录成功进入正式态`。

**2. 首页市场页**
- [ ] 首页能显示 banner、分类、快捷入口、推荐商品、3D 专区。
- [ ] 首页商品卡信息完整：标题、价格、成色、卖家、地点、3D/议价信息。
- [ ] 点击商品卡能进入详情。
- [ ] 下拉刷新正常。
- [ ] 无数据和失败时有合理提示。
- 素材：截图 `首页全景`、`3D 专区`、`推荐商品卡片`。

**3. 搜索与筛选**
- [ ] 搜索框可按关键词搜索商品。
- [ ] 能显示热搜/建议/最近搜索。
- [ ] 排序可切换：`最新`、`人气`、`价格升序`、`价格降序`。
- [ ] 筛选可切换：`价格区间`、`成色`、`仅看 3D`、`仅看可议价`。
- [ ] 组合筛选后结果正确变化。
- [ ] 无结果时有空态提示。
- 素材：录一段 `输入关键词 -> 切换排序 -> 打开筛选 -> 结果变化`。

**4. 商品详情页**
- [ ] 商品详情能显示：标题、现价、原价、成色、瑕疵说明、运费、发货承诺、是否议价、收藏人数。
- [ ] 卖家信息完整：昵称、头像、信用/成交/关注等信任信息。
- [ ] 3D 预览可正常打开；无 3D 时有合理占位。
- [ ] 底部 CTA 正常：`联系卖家`、`立即下单`。
- [ ] 收藏按钮可用，收藏状态刷新后保留。
- [ ] 自己发布的商品不会出现买家操作入口。
- 素材：截图 `详情首屏`、`交易信息卡`、`卖家信息卡`、`3D 预览区域`。

**5. 聊天与议价**
- [ ] 从商品详情能创建会话并进入聊天页。
- [ ] 会话列表能显示最近消息、未读数、商品标题。
- [ ] 聊天详情页顶部、商品卡、消息区、底部输入区完整显示。
- [ ] 空会话状态下仍能看到输入框和快捷问候。
- [ ] 发送文本消息成功，刷新后消息仍在。
- [ ] 快捷话术可点击发送。
- [ ] 发起议价后，聊天中会出现议价卡片。
- [ ] 对方可以接受议价、拒绝议价。
- [ ] 议价接受后，会话中可直接按议价金额下单。
- [ ] 相关订单创建后，聊天页能查看订单。
- [ ] 重点验收你提到的 bug：安卓小屏、键盘弹起后，输入框和发送按钮始终可见、可点，不会出现“只剩安全提醒”的空白状态。
- 素材：必须录屏 `进入聊天 -> 发消息 -> 发起议价 -> 对方接受 -> 按议价下单`。

**6. 地址管理**
- [ ] 地址列表可正常展示高信息密度卡片。
- [ ] 可新增地址。
- [ ] 可编辑地址。
- [ ] 可删除地址。
- [ ] 可设置默认地址。
- [ ] 默认地址在结算页会被优先选中。
- 素材：截图 `地址列表`，录一段 `新增 -> 设默认 -> 编辑`。

**7. 结算与模拟支付**
- [ ] 从商品详情可进入结算页。
- [ ] 结算页能显示：地址卡、商品卡、金额明细、买家备注、支付方式说明。
- [ ] 提交订单后，订单状态应为 `pending_payment`，不是直接已完成。
- [ ] 模拟支付页能显示订单编号、商品金额、运费、应付总额。
- [ ] 点击确认模拟支付后，订单状态变为 `awaiting_shipment`。
- 素材：录一段 `选地址 -> 留言 -> 提交订单 -> 进入模拟支付 -> 支付成功`。

**8. 订单中心：买家视角**
- [ ] 订单列表能按状态查看：`全部`、`待支付`、`待发货`、`待收货`、`已完成`、`售后`。
- [ ] 订单卡信息完整：订单号、商品、实付款、支付状态、履约状态、售后状态。
- [ ] 订单详情能显示：状态横幅、商品卡、金额卡、地址卡、物流卡、时间轴、售后卡、底部动作栏。
- [ ] 待支付订单可取消。
- [ ] 待发货订单可申请退款。
- [ ] 已发货订单可查看物流、确认收货。
- [ ] 已完成订单可去评价。
- [ ] 每个状态下按钮只显示当前可执行动作。
- 素材：截图 `订单列表各状态`、`订单详情整页`。

**9. 订单中心：卖家视角**
- [ ] 卖家能看到自己相关订单。
- [ ] 待发货订单可录入物流并发货。
- [ ] 发货后买家侧能看到物流状态。
- [ ] 退款申请出现后，卖家可同意退款或拒绝退款。
- [ ] 卖家动作执行后，订单详情和通知同步变化。
- 素材：录一段 `卖家发货`，再录一段 `卖家处理退款`。

**10. 收货、售后与纠纷**
- [ ] 买家确认收货后，订单变为 `completed`，商品变为 `sold`。
- [ ] 买家申请退款后，订单变为 `refund_requested`。
- [ ] 卖家同意退款后，订单变为 `refunded`，商品状态恢复 `live`。
- [ ] 卖家拒绝退款后，订单变为 `disputed`。
- [ ] 买家可主动发起纠纷。
- [ ] 售后信息在订单详情中可见：状态、原因、处理说明。
- 素材：必须录一条 `退款成功链路`，最好再补一条 `拒绝退款 -> 纠纷中`。

**11. 评价系统**
- [ ] 只有已完成订单可以进入评价页。
- [ ] 评价草稿可读取和更新。
- [ ] 评价标签可选。
- [ ] 提交评价后，商品评价列表可见。
- [ ] 未完成订单访问评价页应被正确拦截。
- 素材：截图 `评价页`、`评价成功后商品评价列表`。

**四、P1 配套业务验收**
**12. 收藏与我的收藏**
- [ ] 商品详情可收藏/取消收藏。
- [ ] 收藏后商品卡和详情状态一致。
- [ ] 我的收藏页能看到收藏商品。
- [ ] 取消收藏后列表同步消失。
- 素材：录一段 `详情收藏 -> 我的收藏查看 -> 取消收藏`。

**13. 通知中心**
- [ ] 通知按订单/消息/系统分类可浏览。
- [ ] 消息、订单、退款、收货等关键动作会生成通知。
- [ ] 通知卡展示标题、摘要、时间、已读/未读状态。
- [ ] 可单条已读、全部已读。
- [ ] 点击通知能跳到对应订单/聊天/商品。
- 素材：截图 `通知列表`，录一段 `点击通知跳转详情`。

**14. 钱包**
- [ ] 钱包首页能展示可用金额、冻结金额。
- [ ] 模拟支付后有购买/冻结类流水。
- [ ] 退款后有退款类流水。
- [ ] 卖家侧有待结算/退款支出等相关流水。
- 素材：截图 `钱包余额`、`流水列表`。

**15. 会员**
- [ ] 可查看会员方案列表。
- [ ] 可查看当前会员状态。
- [ ] 升级会员后当前方案更新。
- [ ] 会员升级产生对应钱包/状态变化。
- 素材：截图 `会员页`、`升级后当前会员状态`。

**16. 我的页与个人资料**
- [ ] 我的页能看到个人信息、统计、快捷入口、我的商品、地址入口。
- [ ] 个人设置可修改头像、昵称、生日、简介、位置、可见性。
- [ ] 修改后返回“我的”页能看到更新结果。
- 素材：截图 `我的页`、`个人设置页`。

**17. 卖家商品管理**
- [ ] 我的商品列表可见。
- [ ] 卖家可编辑商品基础信息。
- [ ] 卖家可删除商品。
- [ ] 卖家可更新封面。
- [ ] 自己的商品详情不会出现买家动作。
- 素材：录一段 `我的商品 -> 编辑 -> 返回详情查看变化`。

**五、P2 3D 电商特色能力验收**
**18. 3D 展示能力**
- [ ] 3D 商品在首页卡片、详情页、搜索结果中有明显标识。
- [ ] 详情页 3D viewer 可正常加载、旋转、浏览。
- [ ] 无 3D 商品时占位合理，不影响交易决策。
- 素材：必须录屏 `首页卡片 3D 标识 -> 详情页打开 3D`。

**19. 3DGS 发布链路**
- [ ] 卖家能进入发布入口。
- [ ] 可创建 listing draft。
- [ ] 可更新 draft。
- [ ] 可发布 draft 为正式商品。
- [ ] 如果 trainer 可连通，则继续验：上传视频、创建 reconstruction task、训练、校准、发布到 listing。
- [ ] 如果 trainer 不可连通，则至少验已有 3D 商品的展示与交易链路。
- 素材：最好录一条 `发布草稿 -> 发布商品`；如果环境允许，再补 `视频到 3D 商品` 全链路。

**六、稳定性与体验验收**
- [ ] Android 窄屏无布局溢出。
- [ ] 聊天页键盘弹起时，输入区不丢失。
- [ ] 页面返回/重进后状态正确。
- [ ] 刷新后收藏、订单、消息、通知状态一致。
- [ ] 错误接口、空数据、弱网下页面不崩溃。
- [ ] 关键页视觉完成度达标：首页、搜索、详情、聊天、订单、通知、地址。
- 素材：保留 3 组异常素材：`空态`、`加载态`、`错误态`。

**七、建议的最终展示材料清单**
- [ ] 1 条总览录屏：`首页 -> 搜索 -> 详情 -> 3D 预览`
- [ ] 1 条交易录屏：`聊天 -> 议价 -> 下单 -> 模拟支付`
- [ ] 1 条履约录屏：`卖家发货 -> 买家查看物流 -> 确认收货`
- [ ] 1 条售后录屏：`申请退款 -> 卖家同意退款`
- [ ] 1 条信任与服务截图组：`卖家信息`、`服务承诺`、`交易信息卡`
- [ ] 1 条通知跳转录屏：`收到通知 -> 进入订单/聊天`
- [ ] 1 条地址管理录屏：`新增 -> 设默认 -> 结算页自动选中`
- [ ] 1 组订单中心截图：`待支付`、`待发货`、`待收货`、`已完成`、`售后`
- [ ] 1 组聊天截图：`空会话`、`普通消息`、`议价卡片`、`关联订单`
- [ ] 1 组商品详情截图：`首屏`、`3D 区域`、`交易信息`、`卖家信息`
- [ ] 1 组搜索截图：`热搜/建议`、`筛选`、`排序结果`
- [ ] 1 组钱包/会员截图：`余额流水`、`会员方案`
- [ ] 如果可行，再补 1 条 3DGS 发布录屏。

**八、建议的验收结论模板**
- [ ] P0 主链路全部通过：`登录/浏览/详情/聊天/议价/下单/模拟支付/发货/收货`
- [ ] P1 配套能力全部通过：`收藏/评价/通知/地址/钱包/会员/我的商品`
- [ ] P2 3D 能力通过：`3D 展示`，以及在可联网条件下的 `3DGS 发布链路`
- [ ] 无阻塞级问题：空白页、不可点击、错误跳转、关键状态错误
- [ ] 仅保留可接受瑕疵清单，并明确是否影响展示

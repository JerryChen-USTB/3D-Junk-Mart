### P2 — 产品背景与核心理念

**标题：** 为什么需要转物3D？

**正文：**

- 痛点：二手平台"图片和实物不符"，买家无法全面了解商品真实外观
- 方案：用 3D 模型替代传统图片，买家下单前 360° 旋转查看商品
- 技术：3D 高斯散射（3DGS）—— 一段手机视频自动生成可交互 3D 模型

> 📷 **图片位置**：右侧放一张 App 内 3D Viewer 交互查看商品的截图（手指旋转商品的效果）

## 第二部分：3DGS 商品发布流程（4 页，约 1 分半）

### P4 — 3DGS 原理 & 工作链总览

**标题：** 核心亮点 — 3DGS 商品发布流程

**正文：**

- 3DGS 原理：将场景表示为大量三维高斯椭球，通过可微分光栅化训练，实现任意角度实时渲染
- 我们将其封装为自动化工作链，卖家全程无需 3D 建模知识

**工作链总览（流程箭头）：**

```
拍摄视频 → 视频预处理 → 位姿恢复 → [对象分割] → 3DGS 训练 → 模型导出压缩 → 校准发布
```

---

### P5 — 工具链详解（上）：预处理 & 位姿恢复 & 对象分割

**标题：** Step 1~2：预处理与对象分割

**正文：**

| 步骤       | 工具                | 作用                                      |
| ---------- | ------------------- | ----------------------------------------- |
| 视频归一化 | **FFmpeg**          | 统一编码、3fps 抽帧、分辨率调整           |
| 数据集生成 | **ns-process-data** | 调用 COLMAP 完成 SfM 位姿恢复             |
| 位姿恢复   | **COLMAP**          | 从图片帧恢复相机内外参                    |
| 对象分割   | **SAM 2**           | 用户点选商品位置，自动生成全序列前景 Mask |

> 📷 **图片位置**：左下放一张 SAM 2 对象分割标注页面的 App 截图（卖家在参考帧上标注的界面）

### P6 — 工具链详解（下）：训练 & 导出 & 展示

**标题：** Step 3~5：训练、导出与展示

**正文：**

| 步骤          | 工具                                 | 作用                             |
| ------------- | ------------------------------------ | -------------------------------- |
| 3DGS 训练     | **ns-train splatfacto** + **gsplat** | 训练高斯模型，CUDA 内核加速      |
| 模型导出      | **ns-export gaussian-splat**         | 导出 PLY 点云文件                |
| 格式压缩      | **splat-transform**                  | PLY → SOG，大幅压缩体积          |
| 3D 展示与校准 | **PlayCanvas Viewer**                | 旋转/缩放/校准，WebView 嵌入 App |

> 📷 **图片位置**：右侧放一张 Viewer 校准页面的截图（卖家调整模型朝向的界面）

### P8 — 电商功能矩阵

**标题：** 完整的电商交易闭环

**正文：**

除了 3D 展示，转物3D 也实现了完整的电商业务闭环：

| 模块       | 功能                                    |
| ---------- | --------------------------------------- |
| 用户体系   | 账号登录、游客浏览                    |
| 商品浏览   | 首页推荐、分类、3D 专区、搜索筛选排序   |
| 商品详情   | 完整信息 + 内嵌 3D Viewer 360° 查看     |
| 聊天与议价 | 即时消息、发起议价、接受/拒绝           |
| 交易流程   | 下单 → 支付 → 发货 → 物流 → 收货 → 评价 |
| 售后       | 退款申请、纠纷处理                      |
| 账户服务   | 钱包、会员、通知、地址、个人资料        |

**补充描述（表格下方）：**

- 商品详情页中，3D 商品直接嵌入 PlayCanvas Viewer，买家可 360° 旋转、缩放查看
- 买卖双方可针对商品即时聊天，买家可在聊天中发起议价，卖家接受后按议价金额下单
- 交易链路覆盖下单到收货评价的完整流程，支持退款申请与纠纷处理

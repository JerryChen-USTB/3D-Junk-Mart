# 系统设计（四）：使用文档

## 1. 文档说明

转物3D 的交付形态是一个可直接安装使用的 Android APK 应用。用户不需要自行配置 Python、Flutter、数据库或 3DGS 训练环境，只需要在手机上安装 APK，即可使用平台提供的商品浏览、3D 查看、聊天议价、下单履约、退款售后和 3DGS 商品发布等功能。

## 2. 安装与启动

1. 获取转物3D APK 安装包。
2. 在 Android 手机上打开 APK 文件。
3. 如果系统提示“禁止安装未知来源应用”，按照手机提示允许本次安装。
4. 安装完成后，在桌面点击“转物3D”图标启动应用。
5. 首次使用时可选择注册账号、登录已有账号，或以游客身份先浏览商品。

建议在网络稳定的环境下使用。3D 商品模型和三维重建任务需要联网访问后台服务。

## 3. 账号使用

用户可以通过注册页创建新账号，也可以使用演示账号体验完整流程：

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 买家 | `17326882506` | `1234` |
| 卖家 | `18910488457` | `1234` |

游客可以浏览首页、搜索商品、查看商品详情和已有 3D 模型，但不能发布商品、收藏、聊天、议价或下单。涉及交易和个人数据的功能需要登录后使用。

## 4. 买家使用流程

### 4.1 浏览和搜索商品

打开应用后，首页会展示平台推荐、活动海报、3D 商品专区和商品列表。用户可以点击商品卡片进入详情页，也可以进入搜索页，通过关键词、价格、成色、是否支持 3D 模型等条件筛选商品。

### 4.2 查看商品详情和 3D 模型

在商品详情页，用户可以查看商品标题、价格、成色、描述、卖家信息和评价。对于支持 3D 展示的商品，点击 3D 查看入口后，可以通过手势旋转、缩放和平移模型，从多个角度观察商品外观细节。

这是转物3D 的核心功能：买家不只依赖卖家上传的图片，而是可以像拿在手里一样查看商品，从而降低二手交易中的信息不对称。

### 4.3 收藏、聊天和议价

如果用户对商品感兴趣，可以点击收藏，之后在个人中心的“我的收藏”中继续查看。用户也可以点击“联系卖家”进入聊天页，向卖家咨询商品情况。

二手交易支持议价。买家可以在聊天中输入期望价格并发起议价请求，卖家接受后，买家可以按成交价进入下单流程。

### 4.4 下单和收货

买家确认购买后进入订单确认页，选择收货地址并提交订单。课程项目中支付为模拟支付，支付确认后订单进入待发货状态。

卖家发货后，买家可在订单详情页查看物流信息。收到商品后点击确认收货，订单完成，之后可以对交易进行评价。

### 4.5 退款售后

如果订单仍处于待发货或已发货状态，买家可以在订单详情页申请退款。卖家可选择同意或拒绝。卖家同意后订单进入已退款状态；若卖家拒绝，订单可进入纠纷状态。

当前售后功能用于演示退款申请、卖家处理和订单状态流转，不接入真实支付退款通道。

## 5. 卖家使用流程

### 5.1 发布 3D 商品

卖家点击底部导航中的发布入口，进入 3DGS 商品发布流程。整体流程如下：

```text
录制商品视频 -> 填写商品信息 -> 选择质量档位 -> 启动 3D 重建
-> Mask 点选与确认 -> 等待训练完成 -> 校准 3D 模型 -> 发布商品
```

卖家只需要按照页面提示操作，不需要了解 3DGS、COLMAP、SAM2 或模型训练细节。系统会在后台完成视频预处理、相机位姿恢复、对象分割、3DGS 训练和模型导出。

### 5.2 任务状态与模型校准

提交视频后，卖家可以在任务页查看当前处理状态，例如预处理、等待 Mask、训练中、导出中或已完成。

模型生成后，卖家需要在 Viewer 中完成展示校准，包括旋转校正、平移校正、初始视角设置和动画预览确认。校准完成后，商品才能以更合适的姿态展示给买家。

### 5.3 管理商品和订单

发布成功的商品会显示在个人中心的“我的商品”中。卖家可以查看自己发布的商品，也可以在订单页处理买家的订单。

当买家完成支付后，卖家需要填写物流公司和物流单号完成发货。如果买家申请退款，卖家可以在订单详情页同意或拒绝退款。

## 6. 个人中心功能

个人中心集中展示用户资料、发布数量、售出数量、购买数量、收藏数量和常用服务入口。主要功能包括：

| 功能 | 说明 |
| --- | --- |
| 我的商品 | 查看自己发布的商品 |
| 我的收藏 | 查看收藏过的商品 |
| 我的订单 | 查看买入和卖出订单状态 |
| 钱包 | 查看余额、冻结金额和模拟交易流水 |
| 会员 | 查看会员方案和当前会员状态 |
| 通知 | 查看订单、消息、退款等系统通知 |
| 地址 | 管理下单时使用的收货地址 |

## 7. 使用注意事项

- 3D 商品查看和 3DGS 重建都需要网络连接。
- 录制商品视频时，应尽量保持画面稳定，并围绕商品拍摄多个角度。
- 商品应位于画面中心，避免过暗、强反光或背景过于杂乱。
- 课程项目中的支付、钱包和退款为模拟流程，不产生真实资金变动。
- 如果远程训练服务暂时不可用，已发布商品、搜索、聊天、订单等普通电商功能仍可使用，但新视频的 3D 重建可能无法立即完成。
